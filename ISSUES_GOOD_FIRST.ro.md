- [ ] Specifică API-ul widgeturilor (montare/demontare, trimitere/ascultare, ciclu de viață) în docs/widget-api.md
- [ ] Adaugă un widget de sondaj (alegere multiplă, diagramă live cu bare)
- [ ] Adaugă un widget de test compatibil cu fișierele de test Undava
- [ ] Adaugă un widget de notițe lipicioase
- [ ] Adaugă un widget de desen/tablă cu câte o culoare pe telefon
- [ ] Implementează asocierea fără server cu un cod QR și schimb WebRTC ofertă/răspuns
- [ ] Adaugă un sandbox pentru widgeturi (iframe + postMessage) și documentează modelul de permisiuni
- [ ] Testează pe iOS Safari și Android Chrome; consemnează rezultatele în docs/compat.md
- [ ] Adaugă un control pentru profesor „blochează/deblochează telefoanele”
- [ ] Adaugă o temă de accesibilitate cu contrast ridicat și font mare

Creează-le pe toate pe GitHub cu `scripts/create_issues.sh` (cere CLI-ul `gh`).
